■ これは何？

  手元の動画・音声を、目的に合わせて変換するツールです。

  ・MP4 に変換（どこでも再生できる形にそろえる）
  ・サイズを指定して圧縮（メールやチャットに載せられる大きさにする）
  ・音声だけ取り出す（mp3 / m4a / wav）
  ・GIF にする

  いちばんの特徴は、「変換せずに済むときは変換しない」ことです。
  たとえば .mov や .mkv を MP4 にしたいだけなら、入れ物を詰め替える
  だけで済むので、数秒で終わり、画質はまったく落ちません。


■ 動作に必要なもの

  ・Windows 10 / 11（64bit）
  ・インターネット接続（初回だけ。FFmpeg の取得に使います）
  ・空き容量 約 300 MB（下記の部品を置くため）


────────────────────────────────────────────────────────────
■ 使い方
────────────────────────────────────────────────────────────

  1. 「メディアコンバーター.exe」をダブルクリック

     初回だけ、動作に必要な部品（FFmpeg）を取得してよいか聞かれます。
     「はい」を押してください。取得には数分かかります。

  2. ファイルを追加する

     一覧の枠にドラッグ＆ドロップするか、「追加...」を押します。
     フォルダごと入れたいときは「フォルダ追加」です。
     複数入れると、上から順にまとめて処理します。

  3. 「何をするか」を選ぶ

     ・MP4 に変換（互換重視）
         .mov / .mkv / .webm / .avi などを MP4 にします。
         中身がそのまま入れられる場合はコピーするだけなので一瞬です。

     ・サイズを指定して圧縮
         「25 MB に収めたい」といった指定ができます。
         2 パス（下読み → 本番）で回すので、指定した大きさに収まります。

     ・音声だけ取り出す
         mp3 / m4a / wav から選べます。元がすでに同じ形式なら、
         変換せずそのまま取り出します（音質はまったく落ちません）。

     ・GIF にする
         色を調べてから変換する 2 段階の方式なので、
         よくある「色がにじんだ GIF」になりません。

  4. 「変換する」を押す

     緑の文字で「この設定なら: …」と出ているのが、これから行う処理です。
     コピーで済むのか、作り直すのかが分かります。


■ 画質と速度について

  ・画質優先（CPU・遅い）… いちばんきれい。時間はかかります
  ・バランス（おすすめ）… GPU が使えれば GPU を使います
  ・速度優先（GPU）……… とにかく速く。画質は少し落ちます

  GPU（NVIDIA / Intel / AMD）は、実際に使えるか毎回その場で確かめます。
  ドライバが古いなどで使えないときは、自動的に CPU に切り替わります。

  「サイズを指定して圧縮」では、指定サイズに対して解像度が高すぎる場合、
  自動で解像度を下げます。同じ容量なら、そのほうがきれいに見えるためです。


■ 範囲の切り出し

  「範囲」に開始・終了を入れると、その部分だけを変換します。
  1:30 のように「分:秒」で入れてください。

  MP4 変換でコピーが使えるときは、切り出しの位置が近くのキーフレームまで
  数秒ずれることがあります（画質を落とさないための仕組みです）。


────────────────────────────────────────────────────────────
■ 初回に取得される部品について
────────────────────────────────────────────────────────────

  このソフト自体には、変換の機能は入っていません。
  実際の処理は FFmpeg という定番ソフトが行います（約 73 MB）。

  置き場所:
      C:\Users\（ユーザー名）\AppData\Local\johukku\bin

  同梱せずに取得する形にしているのは、次の理由からです。

  ・FFmpeg は GPL というライセンスのソフトです。同梱して配ると
    配布側にソースコードの提供義務が生じます。公式の配布元から
    利用者の PC が直接取得する形なら、その心配がありません。
  ・「Whisper 字幕作成ツール」「メディアダウンローダー」など、
    ほかの johukku 製ツールと同じ場所を使うので、
    すでに入っていれば取得は省かれます。


────────────────────────────────────────────────────────────
■ 警告が出たときは
────────────────────────────────────────────────────────────

  【「Windows によって PC が保護されました」と出る】

     このソフトには有料の署名（デジタル証明書）を付けていないため、
     初回起動時に表示されます。
     「詳細情報」→「実行」で起動できます。

  【ウイルス対策ソフトが反応する】

     この種のツールは誤検知されることがあります。
     心配な場合は、下記でソースコードを公開しているので
     中身を確認してください。

         https://github.com/johukku/media-converter


────────────────────────────────────────────────────────────
■ うまくいかないときは
────────────────────────────────────────────────────────────

  【変換が失敗する・ログに ffmpeg のエラーが出る】

     「部品を入れ直す」を押すと、FFmpeg を取得し直します。

  【GPU を使うと失敗する】

     グラフィックドライバが古い可能性があります。
     「画質優先（CPU）」を選べば、GPU を使わずに変換できます。

  【出来上がりが目標サイズより大きい】

     「速度優先」は 1 パスなので、指定サイズから 1 割ほど前後します。
     きっちり収めたいときは「バランス」か「画質優先」を選んでください。

  【それでも直らない】

     ログ欄の内容を添えて、下記からご連絡ください。

         https://johukku.pages.dev/about/


────────────────────────────────────────────────────────────
■ 削除したいときは
────────────────────────────────────────────────────────────

  「アンインストール.bat」をダブルクリックしてください。
  このフォルダと設定ファイルを削除します。

  ほかのソフトと共有しているもの（FFmpeg）は、消すかどうかを聞きます。
  迷ったら Enter（残す）で大丈夫です。
  消しても、次に使うときにもう一度ダウンロードされるだけです。

  このフォルダに動画など、ツール以外のファイルを置いていた場合は、
  そのファイルは消さず、フォルダも残します。

  レジストリなどは変更していないので、手で削除してもかまいません。
  その場合は、このフォルダに加えて下記を削除してください。

      C:\Users\（ユーザー名）\AppData\Local\johukku\media-converter  … 設定
      C:\Users\（ユーザー名）\AppData\Local\johukku\bin              … FFmpeg（共有）
